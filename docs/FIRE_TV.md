# Fire TV / Vega prototype

`/tv` is a separate, remote-first web view for the Fire TV track. It uses only
web technologies, which the event permits, and implements focus-friendly
navigation with arrow keys plus visible Previous/Next controls. It is a
different experience from the Alexa+ MCP surface: the TV view is optimized for
ten-foot scanning and source selection, while Alexa+ is optimized for spoken
questions.

Run the dashboard and open `http://localhost:5173/tv`. The current local
evidence proves the web view and remote interaction only. A Fire TV/Vega
simulator or device capture is still required before claiming Fire TV track
eligibility or submitting a Fire TV entry.
